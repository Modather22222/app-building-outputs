# Unit Converter

A clean Flutter (Material 3) app that converts length, weight and temperature
across a simple three-tab layout. Type a value, pick the From and To units,
and the result updates live; the swap button flips the direction instantly.

Supported units: mm/cm/m/km/in/ft/yd/mi, g/kg/oz/lb/st/t, and °C/°F/K.

## Run it

```sh
flutter pub get
flutter run
```

Run the smoke test with `flutter test`.
