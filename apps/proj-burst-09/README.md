# Weight Log

Track daily body-weight entries (kg) with a Material 3 UI and an in-memory
data store. The dashboard shows your current weight, a 7-day change summary,
and a simple trend line chart. Swipe an entry left to delete it; use the
"Log weight" button to add or update a weight for today or any past date.

Run it with:

```sh
flutter pub get
flutter run
```
