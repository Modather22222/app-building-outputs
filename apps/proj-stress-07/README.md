# Water Reminder 💧

A compact Flutter (Material 3) app that tracks your daily water intake.
A custom-painted goal ring shows today's progress against your daily goal (default 2000 ml, adjustable in the app bar). Quick-add buttons (+100/+250/+500 ml), undo, and reset-day keep logging fast, and a "Today's log" lists each drink. Hourly reminders show an in-app nudge once per hour while the app is open (toggleable).

Run it with `flutter pub get && flutter run` (tests: `flutter test`).
