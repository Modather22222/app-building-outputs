# Dispatch Probe

A tiny Flutter tap counter: every tap of the big button increments the count
shown as a huge number in the center of the screen, with haptic feedback on
each tap. Tap the reset icon in the app bar to zero it out.

Runs with Material 3 and follows system light/dark mode automatically.

## Run

```sh
flutter pub get
flutter run
```

## Test

```sh
flutter test
```
