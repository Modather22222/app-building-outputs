# Flashcards

A flip-card study deck built with Flutter and Material 3. Tap a card to flip it between question and answer, then mark it correct or wrong - each card keeps its own running tally, and a deck-complete summary lists every card's tally so you can drill again.

## Run

1. `flutter pub get`
2. `flutter run`

Run `flutter test` for the widget tests. The sample trivia deck lives entirely in memory; light and dark themes follow the system setting.
