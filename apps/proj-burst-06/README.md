# Habit Grid

A Material 3 Flutter app for tracking weekly habits: a Monday-to-Sunday check-off
grid where each cell toggles a habit for that day, with a fire-streak badge showing
how many consecutive days you have kept it up. Add habits (with an emoji badge) via
the FAB and delete them from the row menu.

State is in-memory only (resets on restart). Run it with:

```
flutter pub get && flutter run
```
