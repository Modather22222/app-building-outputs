# Acoustic Soundboard

An offline Flutter soundboard: tap a tile to play synthesized funny effects (boing, laser zap, beep boop, pop), lo-fi drum beats and chill chords, or ambient rain, thunder, and brook loops. All audio is generated in pure Dart at runtime as WAV files (no bundled assets) and played through `audioplayers`. Filter tiles with the category chips, tap the toolbar button to stop playback, and both light and dark themes are supported.

## Run

```sh
flutter pub get
flutter run
```
