# Color Match

A compact Flutter app for picking colors by hex code or RGB sliders, with a saved favorites palette.

- Type any hex value (`RRGGBB`, `#RRGGBB`, or `#AARRGGBB`) or drag the R/G/B sliders; the preview shows the live result.
- Tap "Save to palette" to keep a color in the favorites grid; tap a swatch to reload it, or the corner icon to remove it.

## Run

```
flutter pub get
flutter run
```
