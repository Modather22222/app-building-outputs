# BMI Coach

BMI Coach is a compact Material 3 Flutter app that calculates Body Mass Index from
metric height (cm) and weight (kg), shows instant healthy-range guidance (WHO-style
categories plus the healthy weight span for your height), and keeps an in-memory
history of measurements with a custom-painted trend chart that shades the healthy
18.5-25 band.

Run it with:

    flutter pub get
    flutter run

Run the tests with `flutter test`.
