# Memory Match

A pairs-matching memory game built with Flutter (Material 3). A 4x4 grid of
hidden emoji cards is shuffled each round; tap cards to flip them and find all
8 matching pairs. The app tracks your move count and elapsed time, and keeps
your best time and move count from the current session displayed at the top of
the board.

## Run it

```
flutter pub get
flutter run
```

All state is in-memory (no assets, fonts, or platform channels); light and dark
themes follow the system setting.
