# Tip Splitter

A simple Flutter bill splitter: enter a total amount, pick how many people to
divide it among, and see each person's share instantly. Toggle "Round up each
share" to round every share up to the next dollar, with the extra collected
shown at a glance. Built with Material 3 and follows the system light/dark theme.

## Run

```
flutter pub get
flutter run
```

## Test

```
flutter test
```
