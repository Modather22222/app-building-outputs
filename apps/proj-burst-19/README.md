# Unit Quiz

A tiny Flutter quiz app that drills you on unit conversions: kilograms ↔ pounds
and Celsius ↔ Fahrenheit. Each round asks 8 multiple-choice questions with
instant correct/wrong feedback and a running score; at the end you get a score
screen with one-tap replay. Material 3, works in light and dark mode.

## Run

```sh
flutter pub get
flutter run
```

To run the smoke test: `flutter test`
