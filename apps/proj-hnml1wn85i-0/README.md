# Clock

A compact Flutter clock app built with Material 3.

- Clock: live analog and digital clock with a 12/24-hour toggle
- Stopwatch: start/pause, lap splits, and reset
- Timer: countdown picker with progress ring and a time's-up alert
- World Clock: live times for world cities (fixed UTC offsets, no DST)

Run with `flutter run` from this directory; run tests with `flutter test`.
